# Mi Página en Internet 🌐

Este repositorio contiene el código fuente de mi página web personal, desarrollada con el objetivo de aprender, practicar y mostrar conocimientos básicos de desarrollo web utilizando **HTML** y **CSS**.  

El sitio se encuentra desplegado a través de **GitHub Pages** y puede visitarse en el siguiente enlace:  
👉 [https://seergiip.github.io/mi-pagina-en-internet/](https://seergiip.github.io/mi-pagina-en-internet/)

---

## 🧭 Descripción del proyecto

El proyecto consiste en una página web estática que funciona como presentación personal y espacio de práctica en diseño web. Su estructura está compuesta por varias secciones que permiten mostrar información, actividades y trabajos personales.

La finalidad principal es comprender la organización de un proyecto web y la aplicación de estilos mediante CSS, manteniendo un enfoque limpio, semántico y fácilmente escalable.

---

## 🗂️ Estructura del repositori
```
/
├── activitats/ # Contiene las actividades o ejercicios realizados
├── portafoli/ # Sección dedicada al portafolio personal
├── index.html # Página principal del sitio
├── wireframe.html # Estructura base o boceto del diseño
├── .gitattributes # Configuración de Git
└── README.md # Documentación del proyecto
```
---

## ⚙️ Tecnologías utilizadas

- **HTML5:** Lenguaje principal para la estructura del sitio.  
- **CSS3:** Utilizado para el diseño visual y la maquetación.  
- **Git / GitHub:** Control de versiones y publicación mediante GitHub Pages.  

---

## 💻 Visualización local

Para ejecutar el proyecto en un entorno local:

```
git clone https://github.com/seergiip/mi-pagina-en-internet.git
cd mi-pagina-en-internet
```
Luego, abre el archivo index.html en tu navegador preferido.
Opcionalmente, puedes utilizar una extensión como Live Server en Visual Studio Code para una vista en tiempo real de los cambios.

## 🎯 Objetivos del proyecto

- Desarrollar una página web personal como portafolio.
- Practicar la estructura y semántica de HTML.
- Aplicar estilos CSS de manera organizada y eficiente.
- Comprender el flujo de trabajo con Git y GitHub.
